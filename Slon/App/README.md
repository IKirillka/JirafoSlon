# Слон - видеомониторинг

Десктопное приложение для работы с 4 камерами.

В корне `Slon/App` лежит только `app.py`-лаунчер и служебные файлы. Основной код находится в `src/`.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

## Параметры

- `--cameras 0 1 2 3` - индексы камер
- `--width 640` - ширина видео
- `--height 480` - высота видео
- `--fps 30` - частота кадров

## Структура

- `app.py` - запуск приложения
- `src/main_window.py` - главное окно
- `src/camera_worker.py` - поток видеозахвата
- `src/ui_components.py` - элементы интерфейса
- `src/utils.py` - сохранение снимков и утилиты
- `src/config.py` - настройки
- `requirements.txt` - зависимости
