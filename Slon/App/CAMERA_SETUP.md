# Оптимизация для работы с 4 USB камерами на Windows

## Проблемы и решения

### 1. **Драйверы и USB контроллеры**
- Используйте **разные USB порты** на разных хабах (если есть)
- USB 3.0 порты лучше, чем USB 2.0 для видеокамер
- Убедитесь, что установлены актуальные драйверы камер

### 2. **Параметры запуска приложения**

**Рекомендуемые параметры по умолчанию:**
```bash
python app.py --width 640 --height 480 --fps 30
```

**Для более слабых систем:**
```bash
python app.py --width 320 --height 240 --fps 15
```

### 3. **Какие камеры используются**

Проверьте индексы камер:
```bash
# Linux/macOS
python -c "import cv2; print([i for i in range(10) if cv2.VideoCapture(i).isOpened()])"

# Windows PowerShell
python -c "import cv2; print([i for i in range(10) if cv2.VideoCapture(i).isOpened()])"
```

Если видны индексы 0, 1, 2, 3 - все хорошо. Запуск:
```bash
python app.py --cameras 0 1 2 3
```

### 4. **Внутренние оптимизации (уже в коде)**

✅ Минимальный буфер `CAP_PROP_BUFFERSIZE = 1`  
✅ Отключен autofocus `CAP_PROP_AUTOFOCUS = 0`  
✅ Экспоненциальный backoff при ошибках  
✅ Non-blocking захват кадров  
✅ Таймер обновления 100 FPS  
✅ Параллельные потоки для каждой камеры  

### 5. **Проверка производительности**

В статусе камеры видно количество FPS каждой камеры:
- "Камера 0: видео (30fps)" ✅ нормально
- "Камера X: нет сигнала" ❌ проблема с камерой или USB

### 6. **Если все еще лаги**

1. Уменьшите разрешение:
   ```bash
   python app.py --width 320 --height 240 --fps 20
   ```

2. Отключите автофокус на самих камерах (в настройках)

3. Попробуйте подключить камеры к разным USB хабам

4. Проверьте нагрузку на CPU в диспетчере задач (Ctrl+Shift+Esc)

### 7. **Для отладки**

Добавьте в коде логирование в `camera_worker.py`:
```python
print(f"Камера {self.config.index}: {frame_count} кадров")
```

Это покажет, получает ли каждая камера кадры.
