# JirafoSlon

Репозиторий с десктопным приложением **Слон** для видеомониторинга с 4 камерами.

Основной код приложения лежит в `Slon/App`.

## Что умеет приложение

- одновременно открывает до 4 камер
- показывает видеопоток в одном окне
- позволяет задавать разрешение и FPS
- сохраняет снимки с датой и временем
- содержит админ-панель с паролем

## Быстрый старт

```bash
cd Slon/App
pip install -r requirements.txt
python app.py
```

Если нужен запуск с параметрами:

```bash
python app.py --width 640 --height 480 --fps 30
```

## Параметры запуска

- `--cameras 0 1 2 3` - индексы камер
- `--width 640` - ширина потока
- `--height 480` - высота потока
- `--fps 30` - частота кадров

## Структура

- `Slon/App/app.py` - точка входа
- `Slon/App/src/main_window.py` - главное окно
- `Slon/App/src/camera_worker.py` - поток захвата видео
- `Slon/App/src/ui_components.py` - интерфейс и диалоги
- `Slon/App/src/utils.py` - снимки и служебные функции
- `Slon/App/requirements.txt` - зависимости
